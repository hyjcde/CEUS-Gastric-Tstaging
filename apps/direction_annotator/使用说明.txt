    胃癌 EUS 突破方向标注工具 — 使用说明
══════════════════════════════════════════════════════════

【一、概述】

  本工具用于标注胃癌 EUS 超声内镜图像中肿瘤的突破方向，
  帮助 AI 模型更准确地判断 T2/T3 分期。

  标注内容包括：
    1. 3×3 网格标注：在肿瘤区域的 9 个分区中标记哪些位置存在突破
    2. 自由绘制：手动勾画突破区域的精确边界
    3. 每个突破区域可标注可见层数和置信度


【二、数据准备】

  1. 确保你收到的数据文件夹包含以下结构：

     项目根目录/
     ├── direction_annotation_batch.json  ← 标注批次文件（必需）
     ├── dataset/                         ← 图像数据（必需）
     │   ├── internal/
     │   │   ├── train/
     │   │   │   ├── 2018/images/
     │   │   │   ├── 2018/annotations/    ← LabelMe JSON 标注
     │   │   │   └── ...
     │   │   └── ...
     │   └── external/
     │       └── ...
     └── direction_annotations/           ← 标注结果保存位置（自动创建）

  2. 本程序支持两种目录选择方式：

     方式 A：直接选择 dataset 文件夹
       例如：D:\gastric_project\dataset

     方式 B：选择 dataset 的上一级项目根目录
       例如：D:\gastric_project

     程序会自动识别，不需要手动区分。

  3. 默认情况下，程序会优先尝试当前目录下的 dataset 文件夹。

  4. 如果没有 direction_annotation_batch.json 文件，
     请联系研究人员生成。


【三、启动程序】

  方式一（Windows 推荐）：
     双击 "突破方向标注工具 1.0.0.exe" 即可启动。
     这是免安装的绿色版本，无需安装直接运行。
     首次启动可能需要等待 15-30 秒。

  方式二（Linux）：
     双击或在终端运行 "突破方向标注工具-1.0.0.AppImage"

  方式三（开发模式）：
     1. 在命令行进入 direction_annotator 目录
     2. 运行: npm install
     3. 运行: npm run dev
     4. 等待 Electron 窗口自动打开

  首次启动时，程序会优先使用当前目录下的 dataset 文件夹。
  如果该目录可用，程序会直接进入标注页面。
  如果不可用，再手动选择目录即可。

  程序会自动记住上次使用的路径，下次启动会优先恢复。


【四、操作流程】

  1. 设置页面
     ─ 默认会自动填入当前目录下的 dataset 文件夹
     ─ 点击「浏览选择数据集目录」可选择 dataset 文件夹
     ─ 也可以选择 dataset 的上一级项目根目录
     ─ 或在输入框中手动输入路径
     ─ 点击「确认」后自动检查并跳转到标注页面

  2. 标注页面
     ─ 顶部栏：切换视图模式、T 分期筛选、搜索患者 ID
     ─ 中央画布：显示当前图像和标注叠加
     ─ 右侧面板：病例信息、网格控制、Patch 预览、保存

  3. 三种视图模式
     ┌──────────────┬──────────────────────────────────────────┐
     │  完整图 (Q)   │ 显示原始图像 + 绿色 Mask 轮廓           │
     │              │ 滚轮缩放 · 拖拽平移 · R 键重置            │
     ├──────────────┼──────────────────────────────────────────┤
     │ 3×3 网格 (W)  │ 在肿瘤 Mask 区域显示 3×3 分区网格        │
     │              │ 点击网格或按 1-9 标记突破                  │
     │              │ 右侧显示 Patch 预览，点击也可切换           │
     ├──────────────┼──────────────────────────────────────────┤
     │  绘制 (E)    │ 手动勾画突破区域多边形                      │
     │              │ 单击添加顶点 · 双击闭合 · Ctrl+Z 撤销       │
     └──────────────┴──────────────────────────────────────────┘


【五、快捷键】

     ┌─────────┬──────────────────┐
     │  按键    │  功能             │
     ├─────────┼──────────────────┤
     │ 1-9     │ 切换网格突破标记   │
     │ ← →    │ 上一张 / 下一张    │
     │ Q W E  │ 切换视图模式       │
     │ Enter  │ 保存并下一张       │
     │ Ctrl+S │ 保存当前标注       │
     │ Ctrl+Z │ 撤销绘制点/多边形  │
     │ R      │ 重置缩放（完整图）  │
     └─────────┴──────────────────┘


【六、标注要点】

  ✦ 突破区域：肿瘤穿过肌层向外侵犯的位置
  ✦ 可见层数：该区域仍可见几层完整壁层
     - 0 层 = 全穿透（T3 以上）
     - 1-2 层 = 部分穿透
     - 3+ 层 = 壁层基本完整
     - 不确定 = 无法判断
  ✦ 置信度：对突破判断的把握程度（高 / 中 / 低）
  ✦ 没有 Mask 的图片会有黄色提示，可跳过网格/绘制模式
  ✦ 网格模式下，右侧 Patch 小图也可以直接点击，适合快速标注

  标注完成后按 Enter 保存，会自动跳到下一张。
  所有标注保存在 direction_annotations/ 目录下，
  格式为 JSON 文件，可随时查看和修改。


【七、常见问题】

  Q: 启动后白屏 / 加载失败？
  A: 等待 15-30 秒，首次启动需要初始化。
     如果超过 1 分钟仍未加载，检查日志文件（在用户数据目录下）。

  Q: 找不到图像？
  A: 确认你选择的是以下两者之一：
     1) dataset 文件夹
     2) dataset 的上一级项目根目录
     同时确认 dataset/ 目录结构完整。

  Q: 提示“未找到 direction_annotation_batch.json”？
  A: 这通常说明：
     1) 你选错了目录
     2) batch 文件不在项目根目录
     3) batch 文件尚未生成
     建议先尝试重新选择 dataset 文件夹；如果仍失败，请联系研究人员。

  Q: 如何修改已保存的标注？
  A: 重新打开该图片，修改后再次保存即可覆盖。

  Q: 如何更换数据集？
  A: 点击左上角「⚙ 设置」回到设置页面，重新选择目录即可。

  Q: 程序占用内存大？
  A: 这是正常现象，因为程序内嵌了浏览器引擎。
     建议关闭其他不必要的软件。


【八、技术支持】

  如遇到问题，请联系研究人员并附上以下信息：
  1. 操作系统版本
  2. 数据目录路径
  3. 错误截图
  4. 日志文件（位于用户数据目录下的 annotator.log）
