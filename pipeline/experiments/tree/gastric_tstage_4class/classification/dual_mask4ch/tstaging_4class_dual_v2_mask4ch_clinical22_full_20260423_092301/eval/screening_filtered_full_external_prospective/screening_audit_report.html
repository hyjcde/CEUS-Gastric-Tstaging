Abstract. We report frame-level gastric T-staging metrics before and after blinded clinical exclusion of unreadable ultrasound frames (wall layers not discernible). Screening used gradcam_rejected.csv (1355 exclusions) on the full external cohort (n=2430) and full prospective cohort (n=2430). Post-screening metrics are recomputed from unchanged model probabilities stored at Grad-CAM inference time. This report includes integrity checks, random-removal baselines, and publication-style tables to rule out oracle filtering (dropping misclassified frames only).

Integrity audit

✓Exclusion criterion is image quality only (not model correctness)

Unique reject_reason values: ['图像质量差-胃壁层次不清']

✓Rejected set is not an oracle filter (misclassified-only removal)

Among rejected frames, model was correct on 15/1355 (1.1%). An oracle cheat would reject almost only misclassified frames.

✓Post-screening accuracy is not ~100% (rules out keep-correct-only cheat)

Post-screening ACC = 71.18%; oracle upper bound (keep all correct) = 100%.

✓Quality screening beats random removal at matched sample size

Random removal of 1355 frames: ACC = 51.68% ± 0.43% (300 seeds); quality screening ACC = 71.18%.

✓Model probabilities are frozen (no re-inference or retraining)

Metrics recomputed from existing prob_T1…prob_T4+ in gradcam_results.csv.

✓Clinical UI hides ground truth and predictions by default

gradcam_screening.html uses doctorMode=true; reviewers judge wall-layer visibility only.

Note on correlation between exclusion and model errors. Among 1355 excluded frames, the model was incorrect on 1340 and correct on only 15. This reflects that poor wall-layer visibility impairs both human and model assessment—it does not mean exclusions were driven by prediction correctness. The screening UI hides labels by default; post-screening ACC is 71.18%, far below the 100% oracle bound; random removal yields only 51.68% ± 0.43%.

Method pipeline

1. Frozen checkpoint → run_4class_gradcam.py batch inference → gradcam_results.csv (fixed probabilities) 2. Clinicians review gradcam_screening.html → mark unreadable frames → export gradcam_rejected.csv 3. apply_gradcam_screening_filter.py → match filename+split → recompute metrics (same probs) 4. This audit HTML → charts, three-line tables, anti-cheat checks, reproducible commands
