防作弊审计清单

以下检查用于确认：准确率提升来自「去掉不可读图像」，而非「去掉模型分错的样本」等数据泄露。

✓剔除依据仅为图像质量（非模型对错）

reject_reason 唯一取值: ['图像质量差-胃壁层次不清']

✓筛后准确率未达到 100%（排除「只保留分对样本」）

筛后 ACC=71.18%；Oracle 上界（只保留分对）= 100%。

✓筛后准确率显著高于「随机剔除同等数量」

随机剔除 1355 张后 ACC 均值=51.68%（300 次），最大=53.07%；质量筛后 ACC=71.18%。

✓模型预测概率未重新计算（冻结推理结果）

筛后指标直接读取 gradcam_results.csv 中已有的 prob_T1…prob_T4+，未重新跑模型或改权重。

✓临床筛图默认「简易模式」隐藏真值/预测标签

gradcam_screening.html 默认 doctorMode=true，医生仅看图像质量，界面不显示 T 分期真值与预测。

✓每张剔除图可在 rejected CSV 中追溯 uid/filename

剔除列表共 1355 行，含 uid、filename、split、reject_reason、updated_at。

关于「剔除样本多为分错」的说明（非作弊）
被剔除的 1355 张中，模型分错 1340 张、分对仅 15 张。 这是因为图像质量差时模型更难分对，与医生按「胃壁层次是否清晰」剔除相关但不等同。 筛图界面默认简易模式不展示真值/预测；若按分错剔除（Oracle），筛后 ACC 应接近 100%，而实际为 71.18%。 随机剔除同等数量后 ACC 仅约 51.68%（300 次模拟），说明提升非随机波动。

方法链路（可追溯）

1. 冻结 checkpoint → run_4class_gradcam.py 批量推理 → gradcam_results.csv（prob 固定） 2. 临床双击 gradcam_screening.html → 仅按图像质量点「剔除」→ 导出 gradcam_rejected.csv 3. apply_gradcam_screening_filter.py → 按 filename+split 匹配剔除 → 同一 prob 重算 ACC/AUC 4. 本 HTML 审计报告 → 混淆矩阵 / 防作弊对照 / 可复现命令
