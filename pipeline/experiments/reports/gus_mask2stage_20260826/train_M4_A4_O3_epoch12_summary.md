## 1. 这一轮是什么

- 配置：`pipeline/configs/tstaging_4class_gus_mask2stage_20260826.yaml`
- 变体：M4（全图 + context + 区域 + 径向 + 12 维 geom token）/ A4（阈值 Top-K）/ O3（条件有序头）
- 数据：官方 `maincenter_retrospective_v20260821`，train 1062 人，val 128 人
- 输入：图像 + 确认病灶 mask + 最多 10 帧。临床字段和相似例投票不进核心模型
- Backbone：ConvNeXt V2 Tiny，384 + 384 letterbox，AMP + EMA
- Geom：从原始完整 mask 提取 12 维，train 折 z-score（6044 张有效 mask），不在 context 拉伸后计算
- GPU：1（约 3.5 分钟 / epoch）

第一轮开训时 AMP 拦截了 `binary_cross_entropy`。loss 改为 fp32 后重开。本文数字全部来自重开后的 `history_M4_A4_O3.json`。

Val 类别（患者级）：T1 33、T2 11、T3 43、T4+ 41。T2 只有 11 人，硬分类极不稳定。

## 2. 一句话结论

模型已经能分开 **T1 和 T4+ 两端**，排序指标（T2+ / T3+ AUROC、有序 MAE）也在涨。  
**T2 和 T3 的硬分类召回始终是 0**：12 个 epoch 里，从未把任何验证患者判成 T2 或 T3。当前最好 QWK 0.584 主要来自 T1 对 T4 的二分类，不是四期都立住了。

中止时曲线仍在上升（loss 下降、QWK 从 epoch 11 的 0.544 到 12 的 0.584），不能当成已经收敛。

## 7. 曲线怎么走

1. **epoch 1**：全预测 T1。QWK 0。ACC 刚好等于 T1 占比 25.8%。
2. **epoch 2**：突然改成「T1 或 T4」。QWK 冲到 0.420。T4 召回 1.00，但 T1 只有一半对，T3 几乎全进 T4。
3. **epoch 3**：过度偏向 T4（T1 只剩 4 个判对）。QWK 掉回 0.106。这是早期最差的一次回撤。
4. **epoch 4–7**：T1 召回从 0.27 回到 0.70，QWK 回到 0.538。loss 开始明显下降。
5. **epoch 8–10**：early 冻结末期平台。ACC 钉在 0.469，QWK 0.51–0.52。T2/T3 仍然 0。
6. **epoch 11–12**：进入 mid 解冻。loss 0.445 → 0.419，QWK 0.544 → 0.584，ACC 到 0.492。还在涨，就被中止。

解冻日程：1–10 early，11–40 mid，41+ 全开。中止时 train loss 和部分 val 指标仍在改善，因此无法判断完整训练后的最优点；继续可能提升，也可能波动或过拟合。不能写成「后面本该继续涨」。

## 8. 现在能说什么、不能说什么

能说：

- 训练回路是通的：AMP 修复后 12 轮无崩溃，val 每轮可出数。
- 12 维 clean-mask geom + M4 没有立刻崩掉；但也没有把中间期救起来。
- 有序分数比四类 argmax 更有信息。若只看 T3+ AUROC 0.855，会高估分期能力。

不能说：

- 不能报 0.584 为最终 val QWK。
- 不能说 M4 已经学会跨壁层 / T2–T3。
- 不能和 live L3 mask-pool CORAL 比外部中心：这轮没跑 `--eval`，也没跑 phase0。
- 不能把 geom 或 TabPFN 写成这一轮的贡献。Geom 只是单 token；表格基础模型没进训练。

## 10. 建议的下一步（按优先级）

尸检见 `o3_decode_autopsy_epoch12.md`。结论：排序和 0.5 阈值穿越已经有中间类；argmax 把 P(T2)/P(T3) 压没。帧级同样 0 个 T2/T3。不要先堆更复杂网络。

1. 修完整 resume，分离 `last` / `best`，固定 run 目录。否则长训练不稳。
2. 审计并改 O3 决策：乘积构造、argmax vs 阈值穿越、loss 是对 `q` 的全体 BCE（没有 risk-set）。cutpoint 只能在 train OOF 上定。
3. 用 epoch 12 权重做头对照（已完成 0.5 穿越 / 期望分期；下一步 softmax、CORAL、共享严重度 + cutpoints）。
4. 能 resume 则从 epoch 12 续，否则保护备份后重开。设 mid 中期检查：argmax 预测计数若仍是 0/0 个 T2/T3，停，不要盲跑 80。
5. 再做 M4/M5/M6 和区域 cross-attention。多种子。前瞻 425、外部 485 继续锁。

每轮日志应打印：预测 T1/T2/T3/T4 计数、各类召回、三个阈值阳性率、E[Y] 均值。再增加 min class recall 和 middle-class macro recall。
