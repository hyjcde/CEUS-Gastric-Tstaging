# 数据 QC 规范

## 目的

QC 的目标不是“发现有问题”，而是让问题能被分级、复核、修复和追踪。

## QC 的 4 个层级

### 1. 文件层

检查文件是否存在、是否可读、命名是否规范。

### 2. 标注层

检查 annotation、bbox、mask、overlay 是否完整，是否存在空标注、错位、旧版命名。

### 3. 病例层

检查患者信息、病例映射、标签来源、中心和年份是否一致。

### 4. 任务层

检查样本是否真的适合进入定位、分割或分类任务。

## 默认状态字段

建议统一使用这些状态：

- `pending`
- `passed`
- `warning`
- `failed`
- `fixed`
- `excluded`

## 高优先级问题

下面这些问题默认优先处理：

- 缺 annotation 或 mask
- overlay 错位
- 标签来源不清楚
- 患者级重复或冲突
- 外部测试集存在命名或映射异常
