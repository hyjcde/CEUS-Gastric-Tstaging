# 数据切分策略

## 核心原则

数据切分必须以患者级为单位，而不是图像级。

如果一个患者的不同图像同时出现在训练和测试中，就会产生数据泄漏，导致结果看起来比真实情况更好。

## 默认 split 层级

本项目默认保留 5 类用途：

- `train`
- `val`
- `internal_test`
- `prospective_test`
- `external_test`

如果暂时没有前瞻数据，可以先为空，但字段和目录要提前保留。

## 切分顺序

建议按照下面顺序处理：

1. 先做患者去重
2. 再按中心、年份、标签分布做统计
3. 最后再生成 split manifest

## 必须固定的约束

- 同一患者不能跨 split
- 同一中心的不同年份要单独统计
- 外部测试集不能被任何调参过程直接使用
- 如果 Stage 1 和 Stage 2 共用病例，必须在患者级保持一致边界

## 和任务的关系

### 定位

- 以患者级记录检测结果
- 单图像 mAP 只是辅助
- 必须额外记录 ROI 成功率和 fallback 率

### 分割

- 以患者级记录每个病例的最佳、最差和平均表现
- 需要单独保留外部中心表现

### T 分期分类

- 以患者级预测为主
- 图像级结果只用于辅助分析和可视化
