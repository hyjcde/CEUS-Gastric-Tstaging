# 研究主线

## 主线概览

新的默认研究路线如下：

```text
数据注册与清洗
  -> 数据 QC 与患者级 split
  -> 定位模型 baseline
  -> 分割模型 baseline
  -> Stage 1 结果审计
  -> T 分期分类 baseline
  -> 内部/外部验证
  -> 错误分析与可视化
```

## Stage 0：数据准备

先完成这 4 件事：

1. 明确每个样本属于哪个中心、年份、批次和用途。
2. 明确标签来源和可用性。
3. 完成患者级去重和病例映射。
4. 固定训练、验证、内部独立测试、外部测试的边界。

## Stage 1：定位与分割

### 定位模型

目标不是单纯提高检测指标，而是回答：

- 病灶能否稳定被找到
- ROI 能否稳定生成
- 上游定位是否改善后续分割和分类

### 分割模型

目标不是只看内部 Dice，而是回答：

- 内部数据能否稳定出 mask
- 外部中心是否还能保持可用
- predicted mask 是否适合作为 ROI 或第 4 通道输入

## Stage 2：T 分期分类

T 分期分类必须建立在更稳定的 Stage 1 之上。

进入 Stage 2 前，至少应具备：

- 一个可复现的定位 baseline
- 一个可复现的分割 baseline
- 一套固定的患者级 split
- 一套固定的内部/外部验证协议

## 每条主线都要保留的证据

- 数据版本记录
- 配置文件
- 训练日志
- 患者级结果表
- 内部验证结果
- 外部验证结果
- 失败案例复盘材料
