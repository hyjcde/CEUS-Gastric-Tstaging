# 研究主线

## 默认入口

当前项目请先读：

- `docs/mainline/tstaging_current_mainline.md`

这份文件是现在的主线总入口，已经把会议纪要、旧实验和当前 baseline 的关系重新收口。

## 当前路线的最短理解

当前默认路线不是继续大规模扩 `T 分期四分类` 模型，而是：

```text
固定数据边界与 Stage 1 baseline
  -> 用 detection / segmentation 建立稳定 ROI 与 mask 资产
  -> 基于 mask/ROI 设计边缘 patch 对比学习
  -> 先在良恶性任务验证局部监督是否有效
  -> 同步收口 T2/T3 错误分析与证据链
  -> 再决定是否进入新的 T 分期分类路线
```

## 当前只看 3 条判断标准

1. 新实验是否帮助模型更聚焦病灶边缘。
2. 新实验是否帮助验证局部监督在良恶性任务上是否成立。
3. 新实验是否帮助解释 `T2/T3` 的错误来源。

如果一个方向不能回答上面 3 点中的至少 1 点，就不应进入近期优先级。

## 每条主线仍然必须保留的证据

- 数据版本记录
- 配置文件
- 训练日志
- 患者级结果表
- 内部验证结果
- 外部验证结果
- 失败案例复盘材料
