# 项目范围与阶段目标

## 项目目标

本项目面向胃充盈超声的胃癌 T 分期辅助分析，当前采取两阶段主线：

- Stage 1：病灶定位与分割
- Stage 2：基于 Stage 1 输出开展 T 分期分类

当前优先级明确偏向 Stage 1，不再一开始就把主要精力投入到大量四分类模型扩线。

## 当前阶段的主要任务

### 第一优先级

- 整理干净、可复用的数据口径
- 固定数据注册、QC 和患者级 split 规则
- 建立定位模型基线
- 建立分割模型基线
- 固定内部验证和外部验证方式

### 第二优先级

- 把检测框、ROI、mask 和病例级标签连成稳定链路
- 让 Stage 2 的 T 分期分类建立在稳定输入之上

### 第三优先级

- 产出标准化的可视化
- 建立医生审阅和失败案例复盘材料

## 当前不做什么

- 不继续广撒网试大量新 backbone
- 不把旧实验目录整体搬进来
- 不让论文草稿、汇报材料和主线实验目录混在一起
- 不在数据边界不清楚时直接开始新一轮训练

## 成功标准

这个重建版本至少要满足以下条件：

1. 新进入项目的人能在 10 分钟内知道该看哪些文件。
2. 任一实验都能追溯到明确的数据版本、配置版本和验证结果。
3. 定位、分割、分类三条线能通过统一目录和统一命名连接起来。
4. 内部验证、外部验证和可视化从一开始就是固定流程，而不是最后补整理。
