# 验证协议

## 验证分层

所有正式结果默认分成 4 层：

1. 训练内验证
2. 内部独立测试
3. 前瞻测试
4. 外部测试

## 患者级优先

项目对外或对内汇报时，默认优先使用患者级结果。

图像级指标可以保留，但只能作为辅助信息，不能替代患者级结论。

## 各任务最少要报什么

### 定位模型

- Precision
- Recall
- mAP50
- mAP50-95
- ROI 成功率
- fallback 率
- 对后续分割或分类的影响

### 分割模型

- Dice
- IoU
- HD95（如果可稳定计算）
- 内部与外部的分层结果
- 失败病例列表

### T 分期分类

- 患者级 AUC 或等价多分类指标
- BalAcc
- 混淆矩阵
- T1/T2/T3/T4+ 各类召回率
- 按中心或年份分层结果

## 结果目录规则

- `results/internal_validation/`：内部验证成品
- `results/external_validation/`：外部验证成品
- `results/visualizations/`：正式图和 atlas
- `results/reports/`：总结页和报告

## 必留材料

每次正式验证至少保留：

- 患者级预测表
- 聚合指标表
- 失败案例清单
- 一页简短结论
