# 病灶感知的有序多曲线追踪（当前主方法）

日期：2026-08-29。本文是**此刻要跑的胃壁分层算法**。不定 cT，不接公网工作台。

像素三类聚类和 DINO 走廊聚类都还在仓库里，但它们只做**候选**，不是最终分层。最终结果是最多三条细线：实线是病灶外检测到的结构，虚线只是几何预测。

> 在病灶外寻找若干条具有固定顺序、局部平行、曲率连续的细长胃壁结构，再判断这些结构进入病灶后是消失、融合，还是从病灶外侧连续绕过。

---

## 1. 为什么不再把「分成三类像素」当主问题

P040 右侧可以同时看到：走行线附近一条暗带，其下方一条更连续的亮带，上方浅层证据较弱。两个亮层灰度可以几乎一样；病灶和固有肌都可以是低回声。聚类不知道层必须是细长、有序、近似平行的。DINO 的 patch 若比条带宽，特征里已经混了上下组织。

所以：

| 角色 | 做什么 |
|------|--------|
| 灰度峰 / 谷，或以后的聚类、DINO | 每个法向截面上给出候选点 |
| 几何模型 | 把候选点收成最多三条有序细线 |
| 病灶 | 截断正常学习区；禁止自动跨灶重连；参与融合 / 中断 / 绕行 |

黄色走行线是**局部坐标轴**，不是黏膜线，也不是浆膜线。

---

## 2. 对 P040 这类图的读法

蓝色轮廓是病灶，黄色线是医生走向辅助线。若图像下方是胃壁外侧（当前启发式：`+across` 朝图像下方）：

- 黄线下方较连续的亮带：浆膜候选
- 黄线附近的低回声细带：固有肌候选
- 黄线上方浅表亮灰：浅层候选，证据可以不够，允许缺失

若胃腔侧相反，浅层和浆膜对调。有胃腔多边形就用胃腔定向；没有时不要把图像位置当成金标准。以后应让医生点一次「胃腔侧」。

不要强迫每个位置都有三层。

## 3. 当前实现（第一版几何基线）

```text
track_ordered_layers(
    gray, wall, lesion_mask,
    lumen_center=...,
    lesion_poly=...,
    dilate_px=5,
    search_px=18,
    fit_side="right",
)
```

### 3.1 病灶截断

```text
L_valid = L_doctor - Dilate(M_lesion, 5)
```

膨胀 5 px。病灶边界附近的混合像素不参加正常层学习。出图默认只用走行线右侧（x 大于 55% 分位）的正常段。

### 3.2 曲线坐标

走行线加密后，每个站位有：

- `s`：沿走向的站号
- `n`：沿法向的像素距离，黄线上 `n=0`

`+n` 与 `_heading_stations` 一致。有胃腔中心时先指向离开胃腔，再保证平均 `+n` 朝图像下方。

### 3.3 每个法向截面只出候选，不出三类像素

沿法向左右各读 18 px（被膨胀灶挡住的点跳过）：

- 亮层：灰度局部峰，突起至少约 7
- 暗层：灰度局部谷
- 固有肌：最靠近黄线的谷
- 浅层：谷上方（更小的 `n`）最强峰
- 浆膜：谷下方最强峰

某一侧没有合格峰 / 谷，该层在这个 `s` 就是空的。只有一条亮线时，只保留那一层，不补齐三层。

### 3.4 连成细条

每层的 `n(s)` 单独做中值平滑。相邻站跳超过约 5.5 px 的点丢掉。空洞只补最多 2 个站，长缺失保持缺失。

然后加顺序：

```text
n_shallow(s) < n_muscularis(s) < n_serosa(s)
```

交叉则丢掉较浅或较乱的那一侧，不把上下两条亮线收成一条。

### 3.5 实线、虚线、不跨灶重连

- **实线**：只画 `L_valid` 上检测到的点
- **虚线**：从靠近病灶的实线端点沿局部切线外推最多 26 px；进入膨胀灶后仍可画虚线
- 虚线一旦从灶的另一侧穿出，立刻停。左右正常段不自动接成一条「真实连续」层

### 3.6 层状态（允许缺失）

```text
z_l(s) in {detected, missing, fused, uncertain, wrap}
```

| 状态 | 何时 |
|------|------|
| detected | 病灶外实线至少 4 个点 |
| missing | 几乎没有检测 |
| uncertain | 只有很短一截 |
| fused | 暗层灰度接近病灶内部灰度（差 ≤ 18） |
| wrap | 浆膜实线端点沿膨胀灶外缘走约 16 步，灰度仍接近该层，视为外侧绕行，不是中断 |

中断（以后才当旁证，仍不是 cT）需要同时满足：理论路径与灶相交、灶前有可靠正常层、边缘消失或融合、**没有**外侧绕行替代路径。预测线本身不经过灶，不能叫「灶导致的中断」。

## 4. 线段合并（已有接口，第一版几乎用不到）

若以后要把碎段接起来，必须同时满足，不能只看距离：

1. 外推端点足够近
2. 方向差小于约 15–30 度
3. 接上后曲率不突然变大
4. 相对黄线的法向位置属于同一层
5. 亮接亮、暗接暗
6. 连接路径不穿越其他已确定层
7. 跨越病灶只能标成预测虚线

代价：

```text
C(A,B) = a*d + b*d_theta + c*d_kappa + d*d_n + e*d_feat
```

第一版每层只有一条 `n(s)` 序列，不靠这段做主连接。

## 6. 和旧路径的关系

| 旧做法 | 现在 |
|--------|------|
| 走廊像素 k-means 涂黄红绿 | 只当对照，见 WALL_PIXEL_BRUSH_LAYERING.md |
| 法向人数三等分 / 梯度两刀 | 退出主路径 |
| 平行偏移假层次 | 仍不要 |
| DINO token 聚类当层带 | 以后只提供候选点，不直接当层 |
| `fates` 用灶内灰度硬套层号 | 改为融合 / 绕行 / 缺失，仍不是 cT |

排除病灶、固定袋、不定 cT、不接工作台，这几条不变。

## 7. 已知限制

1. 胃腔侧仍可能被启发式翻错。有 `lumen_polygon` 时较好；P019 很斜时浅层/浆膜可能对调。
2. 第一版是每层独立平滑，还不是完整的三路径动态规划。层间距缓慢变化、多候选 Viterbi 是下一步。
3. 绕行只沿膨胀灶外缘走一小段，不是完整的「沿蓝边弯曲追踪」。
4. P008 走行线是涂鸦，曲线会乱。
5. 公网未接。改本文不要 deploy Next。
