# 病灶感知的有序多曲线追踪（当前主方法）

日期：2026-08-29。本文是**此刻要跑的胃壁分层算法**。不定 cT，不接公网工作台。

像素三类聚类和 DINO 走廊聚类都还在仓库里，但它们只做**候选**，不是最终分层。最终结果是**两条有序边界**：上层到肌层、肌层到外层。三层由这两条线夹出来，不再给每个像素贴解剖标签。

## 1. 为什么不再把「分成三类像素」当主问题

P040 右侧可以同时看到：走行线附近一条暗带，其下方一条更连续的亮带，上方浅层证据较弱。两个亮层灰度可以几乎一样；病灶和固有肌都可以是低回声。聚类不知道层必须是细长、有序、近似平行的。DINO 的 patch 若比条带宽，特征里已经混了上下组织。

所以：

| 角色 | 做什么 |
|------|--------|
| 灰度峰 / 谷，或以后的聚类、DINO | 每个法向截面上给出候选点 |
| 几何模型 | 从右向左联合追踪两条边界 |
| 病灶 | 截断正常学习区；禁止自动跨灶重连；参与融合 / 中断 / 绕行 |

黄色走行线是**局部坐标轴**，不是黏膜线，也不是浆膜线。

---

## 2. 对 P040 这类图的读法

蓝色轮廓是病灶，黄色线是医生走向辅助线。若图像下方是胃壁外侧（当前启发式：`+across` 朝图像下方）：

- 黄线下方较连续的亮带：浆膜候选
- 黄线附近的低回声细带：固有肌候选
- 黄线上方浅表亮灰：浅层候选，证据可以不够，允许缺失

若胃腔侧相反，浅层和浆膜对调。有胃腔多边形就用胃腔定向；没有时不要把图像位置当成金标准。以后应让医生点一次「胃腔侧」。

不要强迫每个位置都有三层。

## 3. 当前实现（两条有序边界）

```text
track_ordered_layers(...)
```

输出：

```text
b1(s) = 上层到肌层（亮到暗）
b2(s) = 肌层到外层（暗到亮）
mucosa:      n < b1
muscularis:  b1 <= n < b2
serosa:      n >= b2
```

类别由**有序位置**决定，两个亮层即使灰度一样也不会收成一类。

### 3.1 病灶截断，从右向左

```text
L_valid = L_doctor - Dilate(M_lesion, 5)
```

只用右侧正常段。从 x 最大的清楚站位开始，向病灶方向走。靠近灶时图像项门槛略降，但不强迫补齐两条边。

### 3.2 每个法向截面的图像项

沿法向读 18 px：

- `b1`：左侧（更浅）比右侧更亮
- `b2`：右侧比左侧更亮

证据太弱时该边可以是「不可见」节点，而不是硬找一个噪声峰。

### 3.3 联合动态规划

两条边一起选路径，代价包括：

```text
E = E_image + 0.28 E_smooth + 0.22 E_thickness + 9 E_missing
```

- 平滑：相邻站 `b` 的跳变
- 厚度：`d(s)=b2-b1` 只要求慢慢变，不要求恒定
- 顺序：`b2 >= b1 + 3`
- 缺失：证据强还选空，要付代价；证据弱则允许空

医生走行线本身会打结，逐点法向还会翻转，所以先把走向低通成一条自然弯的墙轴，再用**整段右侧的中位灰度剖面**定三层：亮 / 暗 / 亮。Viterbi 只允许在这个灰度位置附近慢慢偏，两条边几乎平行于墙轴。黏膜和外膜色带只取界面两侧约 4–7 px，不再把整个搜索窗涂满。

### 3.4 怎么画

- **粗实线**：高置信检测
- **细实线**：低置信检测
- **虚线 + 半透明带**：灶内短预测，带宽随距离变大，最多 18 px
- **圆点**：真实追踪停止处
- **绿线**：外层沿膨胀灶外缘仍亮，记为 displaced（受压绕行），不是中断

虚线穿出灶对侧即停，不跨灶重连。

### 3.5 区域状态（不是 cT）

| 状态 | 含义 |
|------|------|
| visible | 影像上这条边或这层清楚 |
| obscured | 影像上不清楚 |
| displaced | 外层受压，沿灶外缘仍连续 |
| interrupted | 局部真实中断（理论路径与灶冲突，且没有绕行） |
| fused | 中间暗带灰度和灶内部接近，不能把整个灶标成肌层 |
| missing | 未检出 |

**看不到浆膜线 ≠ 病理穿透浆膜。** 图上的 pT 只是旁证。不要写 `lost`，也不要用可见性解锁分期。

中断的旁证仍要同时满足：理论路径与灶相交、灶前有可靠正常段、边缘消失或融合、没有外侧绕行。预测线本身不经过灶，不能叫灶导致的中断。

## 4. 线段合并（已有接口，第一版几乎用不到）

若以后要把碎段接起来，必须同时满足，不能只看距离：

1. 外推端点足够近
2. 方向差小于约 15–30 度
3. 接上后曲率不突然变大
4. 相对黄线的法向位置属于同一层
5. 亮接亮、暗接暗
6. 连接路径不穿越其他已确定层
7. 跨越病灶只能标成预测虚线

代价：

```text
C(A,B) = a*d + b*d_theta + c*d_kappa + d*d_n + e*d_feat
```

第一版每层只有一条 `n(s)` 序列，不靠这段做主连接。

## 7. 已知限制

1. 胃腔侧仍可能被启发式翻错。有 `lumen_polygon` 时较好；P019 很斜时浅层/浆膜可能对调。
2. 动态规划还没有显式曲率项；曲率只在外推时裁剪。
3. 绕行仍只沿膨胀灶外缘走一小段，不是完整的沿蓝边追踪。
4. P008 走行线是涂鸦，曲线会乱。
5. 公网未接。改本文不要 deploy Next。
