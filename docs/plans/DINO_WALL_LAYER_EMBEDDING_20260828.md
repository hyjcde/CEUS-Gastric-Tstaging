## 一句话

能用，而且值得做；但正确用法是：**在医生画出的胃壁走廊里，用 DINO token 判断「这段还像正常壁」还是「已经变成肿块 / 伪像」**，而不是用 embedding 去赌黏膜到浆膜的五层像素分割。

现网灰度 1D 聚类先留下当对照。DINO 先当**同一条走廊上的第二种读数**。哪一种更能对齐医生的连续 / 中断 / 无法判断，再决定要不要进 sidecar。

## 1. 为什么现网像素聚类会碰到上限

经腹充盈超声上，人眼大致只能分成亮、中、暗。8 月 27 日会上定的做法是：只在浸润最深的窄带里，按区域把 256 级灰阶聚成这三档，不要全图超分。现网已经落地：

```text
医生走行线 + 病灶
  -> 浸润最深点落到壁上
  -> 切向 x 法向采一块约 56 x 28 的窄带
  -> 对灰度做 1D k-means（对比度大则 k=3，否则 k=2）
  -> 厚度方向压成 暗 / 中 / 亮 条带
  -> 沿走行看两端亮、中间暗 → 疑似中断
```

这套几何脚手架是对的。错的不是「局部聚类」，而是**只拿单个像素的亮度当特征**。

灰度分不出这些都「看起来亮」的东西：

| 都偏亮 | 临床含义 |
|--------|----------|
| 浆膜 / 外缘高回声线 | 要找的层 |
| 黏膜界面、气体界面 | 常被当成壁 |
| 肝包膜、腹壁 | 方向错时更像外缘 |
| 多次反射伪像 | 单帧像断、邻帧还在 |

也分不出这些都「看起来暗」的东西：固有肌、胃腔、坏死灶、声影。医生原话大意：整张图里长得像胃壁的结构太多；只看病灶形态更分不开相邻期。所以分层主线必须回答的不是「这里亮不亮」，而是「**这里还像这条病例自己的正常壁吗**」。

`wall_layer_v2` 已经给过旁证：单独 `echo_loss` 几乎没用（AUC 约 0.51），浆膜中断更有用。P0.2 把 wall SDF 当 ConvNeXt 第 5 通道也 FAIL。这两条都说明：**不要把「壁」压成一张灰度图再塞进分类器**；要把壁当成沿走行的局部证据。

## 2. Embedding 是什么（先把词说清楚）

可以把一张超声图想成很多小方块。DINOv3 ViT-B/16 在 512 输入上会得到 **32 x 32 = 1024 个小方块**，每个小方块是一个 **768 维向量**（token）。这个向量不是亮度，而是模型根据这个小方块**以及它周围的上下文**编出来的「长得像什么」。

三个直觉：

1. **灰度是 1 个数；embedding 是 768 个数。** 前者只知道亮暗，后者还能编码纹理、条带走向、和旁边是不是肿块。
2. **相近的向量 ≈ 同类组织。** 同一条正常浆膜两端的 token，余弦相似度应该高；浆膜 vs 肿块外缘，即使两边都亮，相似度也往往更低。这正好对应协议里的「从锚定段提取本例浆膜模板」。
3. **它已经是区域表示。** 会上说不要按单像素乱分。一个 token 覆盖一片邻域，天然比 1D 灰度 k-means 更接近「按区域聚类」。

仓库里 DINO 已经会提特征，但用途不是分层：

| 现有用法 | 输出 | 是不是本计划 |
|----------|------|--------------|
| 全图 / ROI 分割 | 病灶 mask，Dice | 否。分割已经够用 |
| `cache_dinov3_tstaging_rich_scalars.py` | 层 2/5/8/11 上 lesion / wall / outer 的池化标量 | 否。整区平均掉了走行 |
| Gate C mask pooling | 灶内 / 周边向量，给 TabPFN 做四分类 | 否。要的是分期，不是层图 |
| 现网 `clarifyDeepestEcho` | 灰度三档伪彩 | 对照基线，先保留 |

一句话：**以前用 DINO 回答「这例是 T 几」；本计划改问「这条走廊上，哪一段还像壁」。**

## 3. 核心判断：能做分层特征，不能做五层分割器

2026-07-28 和壁对象计划已经否决「赌五层像素 GT」。经腹超声 SNR 不够支撑黏膜 / 黏膜下 / 固有肌 / 浆膜四张独立 mask。8 月 27 日产品也改成最多 3 档残存层，T3/T4 往往只看浆膜连续性。

因此本计划的对象是：

```text
输入
  crop_ui 全图（去机器 UI，保留解剖）
  病灶多边形
  可选胃腔
  医生浆膜预期走行线（先验，不是中断答案）
  可见度：清楚 / 模糊 / 看不清

输出（草稿，不定 cT）
  沿走行的「像壁」分数
  锚定段模板 vs 查询段的相似度曲线
  连续 / 疑似中断 / 中断 / 无法判断
  可选：走廊内 token 聚类伪彩（壁样 / 肿块样 / 其他）
  可选：1 / 2 / 3 档残存证据（只在医生选了档位时读）
```

不是：

- 五层语义分割
- 全图超分
- 用医生的 T1–T4 当监督再自评
- 把 DINO 层图当成 ConvNet 第 5 通道（P0.2 已 FAIL）

## 4. 决定成败的一刀：必须走廊裁剪，不能用全图 512 token

ViT-B/16 的每个 token 对应 **letterbox 之后 16 像素**。经腹胃壁常常只有大约 5–15 个原图像素厚。裁剪方式会把「一个 token 等于多少原图像素」差出一个数量级：

| 进网方式 | 近似尺度 | 一个 token 约等于 | 对薄壁 |
|----------|----------|-------------------|--------|
| `crop_ui` 全图 letterbox 到 512 | 长边约 800 → 512 | 20–25 原图像素 | 一层壁挤在半个 token 里，分层必死 |
| 病灶 ROI（Gate C / Dual `crop_roi`） | 框住肿块 | 看框有多大 | T3/T4 外缘常在框外或贴边，浆膜被裁掉 |
| **走行走廊裁剪，再 letterbox 到 512** | 例如沿走 80、跨壁 40 | 约 2–4 原图像素 | 厚度方向能排十几个 token，1–3 档才读得动 |

所以本计划的输入**不是**现成的 `dinov3_tstaging_region_scalars`，也**不是** `gt_lesion_crop_upper_bound_v1`。要新做一条：

```text
医生折线平滑成搜索走廊
  -> 在 crop_ui 上裁走廊矩形（沿切向加长，沿法向包住笔刷）
  -> 等比 letterbox 到 512，记下 (scale, ox, oy)
  -> 冻结 DINOv3 取层 2, 5, 8, 11 的 32 x 32 token
  -> 把走廊采样点双线性插回 token 网格（亚 token，不要只取最近格）
```

浅层 2 / 5 更接近局部回声条带；深层 8 / 11 更接近「壁 vs 肿块」。四层都缓存，门控时再选，不要先拍脑袋只用 last-block。

两个必须对照的 backbone（同一走廊、同一套读数）：

1. 官方 LVD-1689M（通用纹理，没被「只要病灶」带偏）
2. 20260511 last-2 adapter（胃超声分割最好数字；可能把壁压成背景）

分割微调过的 DINO **不一定**更适合认壁。这是第一道实验问题，不是假设。

## 5. 三种方法，同一条走廊

几何脚手架（走行线、锚定段 / 查询段、多帧）跟 [浆膜协议](../meetings/2026-08-28_浆膜预期走行线协议.md) 完全共用。只换「走廊里比的是什么」。

| 代号 | 在走廊里比什么 | 对应现状 | 角色 |
|------|----------------|----------|------|
| **M0** | 灰度 1D k-means + 亮-暗-亮 | `wall-echo-clarify.ts` / `detectBrightDarkInterrupt` | 基线，必须始终并列 |
| **M1** | 对 token（先 PCA 到 8–32 维）做 k-means / GMM，再按锚定段把簇标成壁样 / 肿块样 / 其他 | 还没有 | 回答「区域聚类换 embedding 有没有用」 |
| **M2** | 锚定段（两侧可见正常浆膜）的平均 token 当**本例模板**，查询段逐点算余弦 / 距离 | 协议第 3–5 步，灰度还没做成模板 | **主候选**。它直接实现「像不像这条病例自己的壁」 |

推荐默认读 M2，M1 作图，M0 作对照。原因：

- 没有层像素 GT，无监督聚类（M1）很难保证簇 = 解剖层。
- 医生已经给了两端正常壁。本例模板比「全球三簇」更符合经腹超声的个体差异。
- 看不清单独输出「无法判断」，不要把低相似度默认写成中断。

厚度方向（医生选了 2 / 3 档时）可以后做：在法向上对 M2 分数或 M1 簇做 1D 峰，估残存条带数。第一刀只做 T3/T4 浆膜连续性，和协议第一版一致。

伪代码（M2，说明用，不是要抄进前端）：

```python
# 1. 医生折线 -> 锚定段 A_left, A_right；中间是查询段 Q
# 2. 走廊裁剪 + 冻结 DINO -> 每个采样点一个向量 v(s)
# 3. 本例模板：只用来自「可见且清楚」锚定段的向量
template = mean(v(s) for s in A_left + A_right if visibility == "clear")

# 4. 查询段相似度
sim(s) = cosine(v(s), template)          # 可再减一条「肿块模板」做相对分

# 5. 读数（阈值只在 train/另册拟合，不在 Reader v150 上扫）
if visibility == "unclear":
    verdict = "无法判断"
elif both_ends_high and middle_low and multi_frame_agree:
    verdict = "中断"
elif dip_but_single_frame:
    verdict = "疑似中断"   # 更像伪像
else:
    verdict = "连续"
```

相对分（可选，Gate 2 再开）：

```text
score(s) = cosine(v(s), wall_template) - cosine(v(s), lesion_template)
```

`lesion_template` 用病灶 mask 内、靠近查询段的 token。这样「中间变暗但还像壁」和「中间被肿块占据」能分开。灰度 M0 做不到这一点。

## 7. 门控：过了才往下，过不了就停

一次只改一类因素。患者级划分，禁止图像级泄漏。阈值只在 train / 另册拟合。

### Gate 0 — 分辨率自检（不做模型）

在 10–20 张有走行线的图上算 `token_px_in_original`。

- 走廊裁剪后每个 token ≤ 约 4 原图像素 → 往下。
- 仍 ≥ 12 像素 → 加宽走廊或提高进网边长（512 → 768 只作为走廊实验，不重训分割），**不要**先开聚类。

### Gate 1 — 模板真的分得开吗（M2 定性）

同一 backbone、层 2 和层 11 各出一套拼图。看三件事：

1. 两侧锚定段是否高相似、颜色一致。
2. 查询段里医生认为肿块越过的地方，相似度是否掉下去。
3. 肝包膜 / 界面亮线会不会被当成高相似（假壁）。

官方 LVD 与 20260511 adapter 必须各出一套。若 adapter 把壁和背景糊在一起、LVD 还能分开，后面默认 LVD。反过来也记下来。

**过门：** 至少在清楚、双侧锚定的例子上，人能从 M2 热条看出「两端像、中间不像」，且明显好于「中间只是变暗」。

**不过门：** 停。不要立刻 LoRA，不要接分类器。先查走廊是不是裁歪、法向是不是朝腔。

### Gate 2 — 和灰度比一致性（有医生读数之后）

金标准不是病理五层，而是医生在协议下标的 **连续 / 疑似 / 中断 / 无法判断**（可改、可标看不清）。另册收集，不进 Reader v150 自评自涨。

主指标（患者级）：

- 四档一致率、允许「疑似」与「中断」合并后的一致率
- 假中断率（医生标连续或无法判断，模型报中断）
- 漏中断率
- 多帧后假中断是否下降

对照：M0 vs M2 vs「M0 与 M2 都中断才报中断」。

**过门：** M2 假中断低于 M0，且漏中断不升；或联合规则明显降假中断。T3/T4 二分类只作**弱旁证**，不得拿病理 T 训练聚类阈值后再报同一批。

**不过门：** 灰度继续当产品；DINO 只留研究拼图。

### Gate 3 — 才允许进 sidecar

只在 Gate 2 过了以后：

- 分析隧道加一步 `dino_wall_corridor`，复用已加载的冻结 ViT，不要前端跑模型
- 右侧同时显示灰度稿和 DINO 稿，文案写明草稿
- 大字仍是冻结四分类；胃壁草稿不解锁确定 cT
- 改了 Next / 路由 / 请求包装才部署公网；只加 Python 分析、请求体没变，可以先不部署 Next

### Gate 4 — 伪标签与可选 LoRA（后做）

协议已写：医生短线 + 算法路径 + 医生确认 → A/C 级伪标签。A 级才可作像素级走廊标签。C 级（看不清、冲突、配准失败）不用。

有 A 级另册之后，才允许在走廊上加很小的 LoRA，监督是「像壁 / 不像壁」，**不是** T1–T4。正式测试交互不得立刻改阈值再报同一批。

## 8. 和现有两条线怎么相处

```text
公网医生台（主线，先别动算法）
  走行线 + 灰度 M0 + 右侧四档读数

本计划（研究）
  同一走行线 + 走廊 DINO token + M1/M2
      -> 过 Gate 2 再进 sidecar 并列显示

分类研究（Gate C / TabPFN）
  全图或灶周池化，问 T 几
  以后可以吃本计划产出的中断标量
  现在不要把本计划的 token 拼进四分类表
```

P0.2 wall 5ch、只刷病灶形态、相似检索按分期筛，都不做。训练集当时没有胃壁；新标注必须另册、患者级隔离。

## 9. 明确不要做

1. 不要开五层分割数据集，也不要在病灶上空想 3 层自动线。
2. 不要用全图 512 的现成 region scalar 冒充分层特征。
3. 不要用病灶 ROI 裁掉浆膜后再问 T3/T4。
4. 不要生成式超分当诊断依据。
5. 不要把看不清写成中断。
6. 不要把医生 T 既当输入又当真值。
7. 不要在同一 150 例 Reader 上扫阈值、换 Assist、写 self-evolving。
8. 不要把 DINO 走廊图当成 ConvNet 额外通道。
9. 不要还没做 Gate 0 就训 LoRA。
10. 标题和轴不要用中间点 `·`。

## 11. 验收时怎么对别人讲

**对医生：** 现在的亮暗分仍然在。我们试的是让 AI 记住你两端画的正常壁长什么样，再到中间问「还像不像」。中间不像，再提示中断；看不清就说看不清。

**对合作者：** 这是 few-shot 本例模板匹配，监督几乎为零，几何先验来自医生走行线。不是新的 T 分期网络，也不是 SAM 式五层分割。

**对论文：** 创新点仍是「人给出相邻期和走行先验，AI 只读最深局部是否还像壁」。DINO 是实现回声区域特征的一种，灰度是对照。没有医生线、没有另册标签，不要把探针拼图写成性能。

## 12. 开放风险（写进第一份报告）

- 分割 adapter 可能抑制壁纹理；必须以 LVD 对照，不能只报一个 backbone。
- 走廊太窄会裁掉外缘，太宽会混进肝和腔；Gate 0 要扫宽度，不要写死。
- 双线性插 token 仍可能糊掉 1–2 像素的浆膜线；这时 M2 应和灰度 M0 **联合**，而不是互斥替换。
- 没有折线的历史训练集不能假装有分层 GT。
- 前端跑不动 ViT；产品路径只能走分析隧道。
