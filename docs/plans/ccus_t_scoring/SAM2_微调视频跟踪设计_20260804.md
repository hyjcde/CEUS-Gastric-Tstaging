# 胃超声阅片：微调 SAM2 全视频跟踪设计（2026-08-04）

## 目标

在工作站 GPU 上使用胃超声微调 checkpoint，对医生在锚点帧完成的点击/框选执行全视频 mask propagation。公网只负责页面与请求转发，推理仍经 SSH 隧道回到工作站。

全视频传播不能等同于“每 500 ms 重新跑一次单帧分割”：后者会产生请求滞后、mask 抖动和响应覆盖旧帧的问题。

## 文献依据与工程映射

1. **SAM 2**：Ravi et al., *SAM 2: Segment Anything in Images and Videos*, arXiv:2408.00714. SAM 2 的 video predictor 使用 streaming memory，并支持在任意帧追加提示修正；本实现使用其 `init_state → add_new_points_or_box → propagate_in_video` 路径。
   - https://arxiv.org/abs/2408.00714
2. **XMem**：Cheng and Schwing, *XMem: Long-Term Video Object Segmentation with an Atkinson-Shiffrin Memory Model*, ECCV 2022, arXiv:2207.07115。其短期/工作/长期记忆思想对应本项目的短期传播、锚点保留和失败重锚定；暂不把 XMem 直接替换进临床服务。
   - https://arxiv.org/abs/2207.07115
3. **AOT**：Yang et al., *Associating Objects with Transformers for Video Object Segmentation*, NeurIPS 2021, arXiv:2106.02638。其 short-term / long-term temporal attention 支持“局部平滑 + 长时回看”的设计取向。
   - https://arxiv.org/abs/2106.02638
4. **超声时序一致性**：DeformFlowNet 将 optical-flow constraint 用于超声视频组织分割，强调跨帧形变约束，而不是独立处理每帧。
   - https://www.sciencedirect.com/science/article/abs/pii/S174680942500463X
5. **超声跟踪先验**：CEUS 病灶长期跟踪研究将 Lucas–Kanade optical flow、Kalman motion prior 和 template update 结合，说明超声跟踪需要同时利用运动、外观和模板更新。
   - https://doi.org/10.3389/fphys.2023.1180713
6. **不确定性记忆**：UAMP 将 appearance / motion uncertainty 与短期、长期记忆选择结合，用于抑制错误累积。本项目先采用可审计的面积、质心、边界和分数门控，后续再接显式外观不确定性。
   - https://doi.org/10.1371/journal.pone.0353156

## 当前实现

- 模型：`sabm_gus_sam2_finetune_r001/best_sabm_gus_sam2.pt`。
- 配置：`configs/sam2.1/sam2.1_hiera_t.yaml`；checkpoint 中的 `sam2_model.*` 权重已验证可无缺失注入 `SAM2VideoPredictor`。
- 推理：`scripts/sam2_video_tracker.py`，使用 GPU、CPU offload 的 SAM2 原生视频 memory；支持前向、后向和双向传播。
- 质量门：最小/最大面积比例、面积变化、质心跳变；失败帧不继续写入 accepted mask，并返回 `needs_reanchor`。
- 前端：`ReaderWorkbench` 增加「全视频传播」；结果按当前播放时间选择最近 accepted mask，播放时不再每 500 ms 覆盖式重跑单帧 SAM。
- 快速路径：点击/框选仍使用微调 image predictor；全视频传播由医生显式触发，避免页面打开即占满 GPU。

## 安全边界

- 传播质量门失败时停在最后一个 accepted frame，提示医生重新锚定。
- 不把传播结果直接当作病理真值或自动最终分期。
- GPU 断开时保留单帧交互路径，不静默伪造连续 mask。
- 公网代理的全视频请求超时已放宽到 600 秒；公网不保存其他队列数据。

## 验证记录

- 微调 checkpoint 视频传播：21 帧前向传播约 2.1–2.3 秒，状态 `completed`。
- 公网 Next → Auth proxy → SSH tunnel → 工作站 GPU → 返回 JSON 链路已验证。
- 当前仍需在完整 150 例上做离线传播质量评估：accepted-frame ratio、area/centroid jump、re-anchor rate、医生可接受连续性和端到端延迟。
