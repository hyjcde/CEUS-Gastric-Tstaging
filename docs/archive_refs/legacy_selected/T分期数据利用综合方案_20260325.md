# 口服超声造影胃充盈超声检查（Oral Contrast-Enhanced Gastric Ultrasonography）T 分期：数据利用综合方案

**日期**：2026-03-25（初稿）→ 2026-03-26（v2，融入临床文献洞察）  
**状态**：方案设计 v2，待评审执行  
**分类体系**：4-class（T1 / T2 / T3 / T4+）

---

## 背景

### 检查方式

本项目的检查方式是**胃充盈超声检查**（Oral Contrast-Enhanced Gastric Ultrasonography），属于**经腹超声**而非内镜超声（EUS）。患者口服超声造影剂后，利用充盈的胃腔作为声学窗口，通过体表凸阵探头（频率 1-6 MHz）观察胃壁各层结构及病灶侵犯深度。

> **定位说明**：根据《胃癌诊疗指南（2022）》，内镜超声（EUS）是"胃肠道肿瘤局部分期的最精确方法"（T 分期准确率 70-90%）。经腹充盈超声的临床定位是 **T 分期的有益补充和筛查工具**，其优势在于无创、可及性高、适合基层和筛查场景。本项目的 AI 系统目标是：在基层/筛查场景下辅助经腹超声实现初步 T 分期评估，指导是否需要进一步 EUS/CT 精查。

### T 分期的物理基础：胃壁五层结构

根据《口服造影剂胃超声检查规范操作专家共识意见（2020）》，正常胃壁声像图呈 **"高-低-高-低-高"五层结构**：

| 超声层 | 回声 | 解剖结构 | T 分期意义 |
|--------|------|---------|-----------| 
| 第1层 | 高回声 | 胃腔界面 + 黏膜浅层 (m) | T1a: 病灶限于此层 |
| 第2层 | 低回声 | 黏膜肌层 (mm) | T1a/T1b 分界 |
| 第3层 | 高回声 | 黏膜下层 (sm) | T1b: 病灶达此层 |
| 第4层 | 低回声 | 固有肌层 (mp) | **T2: 侵犯此层但未穿透** |
| 第5层 | 高回声 | 浆膜层 + 浆膜外脂肪 (s) | T3: 穿透浆膜下; T4: 穿透浆膜 |

**对模型的关键启示**：
- T2 vs T3 的区分本质上是看**第4层（固有肌层）是否被完全穿透**
- 经腹凸阵探头的分辨率远低于 EUS 高频探头，五层结构在很多情况下**肉眼都难以辨认**
- 模型能学到的更可能是**间接征象**：肿瘤大小、形状不规则度、浆膜面是否光滑、边界清晰度等

### T 分期对治疗决策的影响（非对称代价）

根据 AJCC/UICC 第8版 TNM 分期和《胃癌诊疗指南（2022）》：

| T 分期 | 定义 | 治疗决策 |
|--------|------|---------|
| T1（N0） | 侵犯黏膜或黏膜下层 | 内镜切除（ESD/EMR）或改良手术 |
| T2（N0） | 侵犯固有肌层 | 标准 D2 手术 |
| T3/T4a（N+） | 穿透浆膜下或浆膜 | **新辅助化疗 → 手术** |
| T4b | 侵犯邻近器官 | 联合脏器切除或转化治疗 |

**T2 误判的临床代价是非对称的**：
- T2 → 误判 T1：漏掉手术 → **致命错误**（代价最高）
- T2 → 误判 T3：多做化疗 → 过度治疗但不致命
- T1 → 误判 T2：多做手术 → 过度治疗
- T3 → 误判 T2：漏掉化疗 → 治疗不足

→ 这种非对称性应反映在**损失函数设计和评估指标**中（详见策略 A4）。

### 造影模式

造影剂分两类，对应不同的图像表现：
- **无回声造影剂（anechoic contrast agent）**：如饮用水，胃腔在超声图像上表现为**暗色/无回声区**
- **有回声造影剂（echogenic contrast agent）**：如商业胃窗超声造影剂，胃腔在超声图像上表现为**亮色/强回声区**（专家共识为 A 级强烈推荐）

两种造影剂都属于口服超声造影剂，检查目的相同（评估胃壁层次和肿瘤侵犯深度），但根据专家共识：
- **无回声**利于显示高回声病灶，**可能漏检低回声病灶**
- **有回声**利于显示低回声病灶，胃壁层次显示更稳定
- 两者的**声衰减系数不同** → 不仅是亮暗反转，而是频率依赖的衰减差异
- 无回声时常需**降低远场增益**应对后壁回声增强 → 同一病灶在两种模式下增益设置可能不同

→ CLAHE 等全局增强**无法完全消除**两种模式的本质差异，模型需要造影模式感知的设计（详见策略 A5）。

现有数据中的造影模式分布：
- Historical Pool 视频：**喝水（无回声）215 个** / **造影（有回声）152 个**
- 图像训练集：未在路径/元数据中标记造影模式，需要进一步确认

### 解剖部位对图像的系统性影响

专家共识详述了不同部位胃壁的正常差异：
- 胃窦壁厚 4-6mm > 胃体 3-5mm > 胃底 ≤3mm
- 不同部位的图像形态系统性不同（胃体中上部类圆形、中下部椭圆形、胃窦管道状）
- 小弯和大弯部分胃壁与声束夹角甚小，可出现**侧壁回声失落伪像**
- **胃角和胃窦**是溃疡和胃癌好发部位

→ 如果未标注解剖部位，模型可能把"部位形态差异"当作"T 分期差异"来学习（详见策略 A6）。

| 验证集 | 1,117 | 167 | 96.9% | 211 | 83 | 416 | 407 | 同上 |
| 前瞻测试 | 253 | 54 | 有 | 40 | 32 | 100 | 81 | 协和(内部) |

- 推理/落地时**没有 mask 勾画**，也没有人手动框 ROI

视频数据**没有 mask 勾画**，但部分有 T 分期标签。视频是 EUS 检查的原始产出，是临床落地的真实输入形态。

| 来源 | 文件数 | 患者数 | 有 T 标签 | T1 | T2 | T3 | T4+ | 格式 | 造影模式 | 备注 |

**视频与图像的重叠关系**：
- 2018+2024 共 200 患者同时有图像和视频，其中 158 在训练集、19 在验证集
- 2025 共 213 患者有标签，193 在图像数据集中（多数为前瞻测试集），20 仅有视频
- 视频中 T2 极少（2018 仅 4 例、2024 仅 5 例、2025 仅 22 例）

### 1.3 GT Mask 的信息量验证（已完成）

对 9,959 张有 mask 的图像做了形态学和纹理分析：

- 提取 24 个特征，**22 个与 T 分期显著关联**（Kruskal-Wallis, p<0.05）
- 最强信号：曲率方差（H=1918.7）、最大曲率（H=1897.2）、轮廓点数（H=1869.8）
- T2 vs T3 最佳区分：curvature_max（Cohen's d=0.483）、边界梯度异质性（d=0.288）
- 纯特征分类：GradientBoosting AUC=0.706，但 T2 recall 仅 7.6%
- **结论**：mask 形状包含 T 分期信息，但不足以区分 T2，需要深度模型学习图像中的边界层次

## 二、核心矛盾

```
训练时：  静态截图 + GT mask + ROI   → 信息丰富，但这些推理时都不存在
推理时：  EUS 视频流（裸视频）        → 没有截图、没有 mask、没有 ROI

中间的鸿沟：
  1. mask → 推理时没有，分割模型预测不可靠（HD95 > 30mm）
  2. ROI  → 推理时需要人工框选或检测模型，增加了依赖
  3. 静态图 → 推理时是连续视频，存在域差异（动态模糊、帧间冗余）
  4. T2    → 样本最少，又是最难的，医生自己也经常分不清
  5. 造影模式 → 无回声(喝水)和有回声(造影)图像表现差异大，
               模型需要在两种模式下都能工作
```

### 造影模式对模型的影响

（详见背景-造影模式章节）核心要点：无回声和有回声造影剂之间的差异**不是简单的亮暗反转**，而是涉及声衰减系数、增益设置、病灶可见性等多维度差异。模型需要造影模式感知的设计或充分混合的训练数据。

## 三、策略设计

### 3.1 总体思路

不是"图像 vs 视频"的选择题，而是**图像训练能力 → 视频落地应用**的接力：

```
[图像 + mask]                    [视频]
    │                               │
    ├─ 训练 backbone "看边界"        │
    │   (attention guidance loss)   │
    │   (border contrastive)        │
    │                               │
    ├─ backbone 冻结 ────────────→ 提取视频帧特征
    │                               │
    │                           Video MIL 训练
    │                               │
    │                           输出：裸视频 → T分期
    │                                         + 关键帧
    │                                         + 注意力图
```

### 3.2 路线 A：图像模型改进（立即可做，零成本）

**目标**：用 GT mask 训练出更好的 backbone，但推理时不依赖 mask。

**A1：Attention Guidance Loss**

训练时用 GT mask 生成边界注意力目标，作为辅助 loss 引导模型的 GradCAM 聚焦到病灶边界：

```
border_target = dilate(mask, 15) - erode(mask, 5)   # 边界带
L_total = L_classification + λ * MSE(GradCAM, border_target)
```

推理时只跑前向传播，不需要 mask。这是目前**唯一没有训练-推理鸿沟的 mask 利用方式**。

**A2：Border Contrastive Learning（已有，继续推进）**

现有 contrastive pipeline 的边界 patch vs 远处 patch 对比。Mask 仅用于采样 patch 位置，推理时模型直接对整张图做分类。

**A3：形态学特征作为正则化 loss（非输入）**

将 mask 形态学特征（curvature_max, solidity 等）作为辅助预测目标而非输入，训练 backbone 的中间层能隐式编码形状信息。推理时这些辅助头被丢弃。

**A4：面向临床的非对称损失函数（新增）**

基于 T 分期误判的临床代价差异，用**代价敏感损失**替代普通交叉熵：

```python
# T 分期误判代价矩阵（行=真实，列=预测）
#              pred_T1  pred_T2  pred_T3  pred_T4
cost_matrix = [
    [0.0,     2.0,     1.0,     1.0],    # true T1: 过度治疗
    [5.0,     0.0,     1.5,     1.5],    # true T2: 漏掉手术代价最高
    [2.0,     3.0,     0.0,     1.0],    # true T3: 漏掉化疗
    [2.0,     2.0,     2.0,     0.0],    # true T4: 漏掉联合切除
]
# L_total = L_classification_weighted + λ_attn * L_attention + λ_morph * L_morphology
```

核心逻辑：T2→T1 的漏诊（代价 5.0）远大于 T2→T3 的过度治疗（代价 1.5）。这也可以体现为后处理阶段的**决策阈值不对称调整**。

**A5：造影模式感知训练（新增）**

针对无回声/有回声造影剂的图像差异：

1. **数据准备**（零成本）：用图像亮度直方图自动分类训练集中每张图的造影模式，加入 metadata
2. **Conditional BatchNorm**：backbone 中的 BN 层按造影模式切换参数（类似 domain adaptation），让模型学习在不同造影模式下关注不同纹理特征
3. **造影模式增强**（中期）：训练时对无回声图像做受控的亮度/对比度变换模拟有回声效果（反之亦然），增强跨模式鲁棒性

推理时如果造影模式已知则直接指定，未知则用自动分类器预测。

**A6：解剖部位作为先验知识（新增）**

不同胃壁部位的正常壁厚、形态、T 分期分布存在系统性差异：

1. 如果临床数据有**病灶解剖部位**（贲门/胃底/胃体/胃角/胃窦），可作为条件输入
2. 部位特异的正常壁厚（胃窦 4-6mm > 胃体 3-5mm > 胃底 ≤3mm）可提供"基线"参考
3. 即使不直接作为输入，也应在分析中检查**模型在不同部位的性能差异**，避免部位混淆

### 3.3 路线 B：视频 MIL（中期，核心落地路线）

**目标**：直接输入裸视频 → 输出 T 分期，匹配临床真实场景。

**为什么视频有优势**：
1. 临床产出就是视频，无需额外截图/标注步骤
2. 一段视频包含探头从多个角度扫过病灶的信息 → 天然的多切面观察
3. Video MIL 的 temporal attention 自动学习哪些帧包含关键信息（如边界清晰的帧）
4. 不依赖 mask、ROI、分割模型
5. 标准检查流程要求在病变部位保存"**十字交叉**"切面图 → 视频中天然包含长轴+短轴两个正交方向的信息

**实施步骤**：

| 步骤 | 内容 | 输入 | 输出 |
|------|------|------|------|
| B1 | 建立完整的 video ↔ T-stage 映射 | 视频文件 + 临床表 | mapping CSV |
| B2 | 视频关键帧抽取 | 视频文件 | 每视频 N 帧（如 32-64） |
| B3 | 用路线 A 训练的 backbone 提取帧特征 | 关键帧图像 | [N × feature_dim] |
| B4 | 训练 Video MIL（AttentionMIL / TransMIL） | 帧特征 + patient T-stage | 分类模型 |
| B5 | 评估 + 可解释性 | 测试视频 | T-stage + 关键帧 + attention heatmap |

**数据划分考虑**：
- 2018+2024 视频（200 患者有标签）→ 用于训练 Video MIL（但它们也在图像训练集里，不能作为独立测试）
- 2025 视频（213 患者）→ 其中 193 和图像测试集重叠 → 需要仔细设计哪些做训练、哪些做测试
- 严格原则：**同一患者的图像和视频不能同时出现在训练和测试中**

**Video MIL 的训练数据量问题**：
- 有标签的视频患者总计 ~413 人，其中约 200 人的图像已用于训练 backbone
- 可用于 Video MIL 训练的：~200 人（2018+2024，已泄漏到图像训练集）
- 可用于独立测试的：~213 人（2025 协和）
- 这个量对 Video MIL 来说**刚好够用**（MIL 是轻量模型，backbone 已预训练）

### 3.4 路线 C：医生方向性标注（看需求推进）

**目标**：在已有 GT mask 上追加"侵犯方向 + 可见层数"标注，提供目前所有方法都缺少的监督信号。

**标注内容**：在 mask 轮廓上标 1-3 个"侵犯最深点"，每个点标注该方向外侧可见胃壁层数（0/1/2/3+/不确定）。

**标注格式**：扩展 LabelMe JSON，追加 `invasion_point` 类型的 point 标注 + flags。

**与路线 A/B 的关系**：
- 方向标注主要服务于路线 A（改进 backbone），间接提升路线 B（更好的帧特征）
- 不是必须的，但如果路线 A 的 attention guidance 效果不够好，方向标注能提供更精确的监督
- 试点 50 张 T2/T3 即可验证价值，不需要大量标注

## 四、关键决策点

### 决策 1：视频数据的训练/测试划分

| 方案 | 训练 | 测试 | 优点 | 缺点 |
|------|------|------|------|------|
| A: 严格独立 | 2018+2024 视频（~200人） | 2025 视频（213人） | 完全独立，结果可信 | 训练集和图像训练集重叠 |
| B: 混合 | 图像train患者的视频 + 2025部分 | 2025其余 + 外部 | 训练量大 | 需要仔细防泄漏 |

**推荐方案 A**：2025 协和视频作为独立测试集，2018+2024 视频用于 Video MIL 训练。这样视频测试和图像训练完全独立。

### 决策 2：图像 backbone 训练优先做什么

| 优先级 | 任务 | 依赖 | 预期收益 |
|--------|------|------|---------|
| 1 | Attention Guidance Loss [A1] | GT mask（已有） | GradCAM 改善，backbone 质量提升 |
| 2 | 非对称损失函数 [A4] | 无额外依赖 | T2 召回率提升，符合临床决策逻辑 |
| 3 | 造影模式自动分类 + 感知训练 [A5] | 需自动分类造影模式 | 跨模式泛化能力 |
| 4 | Border Contrastive [A2]（已有框架） | GT mask（已有） | 边界区分能力 |
| 5 | 解剖部位分析 [A6] | 需临床表中部位信息 | 避免部位混淆，按部位优化 |
| 6 | 方向标注融入 [C] | 需要新标注 | T2 区分力提升（待验证） |

### 决策 3：视频处理策略

| 选项 | 方法 | 适用场景 |
|------|------|---------|
| 均匀抽帧 | 每 N 帧取 1 帧 | 简单 baseline |
| 运动检测抽帧 | 帧间差异 > 阈值时取帧 | 减少冗余 |
| 聚类抽帧 | 特征聚类后每簇取代表帧 | 保留多样性 |
| 全帧 + MIL | 所有帧都送 MIL，attention 自动选 | 最大化信息利用 |
| **临床行为感知抽帧** | 基于扫查行为模式的智能选取 | **推荐方案**（见下） |

**临床行为感知抽帧的设计依据**（来自专家共识的标准检查流程）：

标准扫查顺序：贲门/胃底 → 胃体中上/中下部 → 胃角 → 胃窦 → 幽门/十二指肠 → 回到贲门/胃底。医生在发现病灶后的典型行为模式：

1. **停留区域**：探头减速、反复扫查 → 帧间光流小但内容持续变化 = 关键帧候选区
2. **十字交叉切面**：长轴和短轴切换 → 图像旋转约 90°，转换点附近包含正交方向信息
3. **放大段**：减小显示深度放大影像 → 通常在仔细观察病变
4. **快速移动段**：快速扫过非病变区域 → 高帧间差异 + 模糊 → 应低权重或丢弃

→ 实现方式：结合光流分析（停留检测）+ 帧间旋转检测（十字交叉）+ 视野变化检测（放大段）的多信号融合。

## 附录 C：Attention Guidance Loss 初步验证（2026-03-26）

### 实验设计

**核心思路**：用 GT mask 的边界带（dilate - erode）引导 backbone feature map 的空间注意力，推理时不需要 mask。

**技术实现**：
- 在 `DualBranchClassifier` 训练时返回 global backbone 的 feature map (B,C,H,W)
- 对 feature map 取 channel L2-norm → spatial attention map
- 用 GT mask border target 计算 MSE loss，作为辅助 loss 加入总 loss
- `L_total = L_classification + λ * MSE(attention_map, border_target)`

**实验矩阵**（全部完成）：

| 实验 | lambda | Val AUC | 前瞻AUC | 前瞻T2R | 前瞻T3R | 外部AUC | Epoch |
|------|--------|---------|---------|---------|---------|---------|-------|
| boundary_boost_frozen (历史最佳) | — (mask4ch) | 0.718 | **0.752** | 15.6% | **33.0%** | **0.659** | 11 |
| attn_guidance v1 | 0.5 | 0.704 | — | — | — | — | 7 (killed) |
| **attn_guidance v2** | **0.1** | **0.721** | 0.727 | **21.9%** | 18.0% | 0.638 | 8/33 |
| **两阶段 (pretrain→finetune)** | — | **0.719** | **0.739** | 15.6% | **33.0%** | 0.620 | 5/30 |
| baseline_no_mask | — | 0.698 | 0.681 | 3.1% | 12.0% | 0.635 | 10/35 |

### GradCAM-Border Alignment 量化对比

| 指标 | Attn Guidance v2 | Baseline (mt_clean) | Δ | 含义 |
|------|:---:|:---:|:---:|------|
| mean_iou | **0.098** | 0.041 | +139% | GradCAM 热区与 border 的 IoU |
| mean_dice | **0.168** | 0.073 | +130% | GradCAM 热区与 border 的 Dice |
| mean_correlation | **0.177** | 0.055 | +222% | GradCAM 与 border 的空间相关性 |
| specificity_ratio | **4.28** | 1.83 | +134% | border 内外 GradCAM 强度比 |
| val_accuracy | 0.458 | **0.542** | -15.5% | 验证集准确率（attention guidance 低） |

**Per-class GradCAM-border correlation**：

| 类别 | Attn Guidance v2 | Baseline | Δ |
|------|:---:|:---:|:---:|
| T1 | **0.128** | 0.032 | +300% |

| T3 | **0.182** | 0.105 | +73% |
| T4+ | **0.201** | 0.003 | +6600% |

### 完整结论

#### 1. Attention Guidance 确实让模型"看向边界"（GradCAM 证实）

| 指标 | Attn Guidance v2 | Baseline | 提升 |
|------|:---:|:---:|:---:|
| GradCAM-border IoU | **0.098** | 0.041 | +139% |
| GradCAM-border Dice | **0.168** | 0.073 | +130% |
| 空间相关性 | **0.177** | 0.055 | +222% |
| border 内/外注意力比 | **4.28** | 1.83 | +134% |

#### 2. 两阶段方案是最佳策略

| 对比维度 | 两阶段 | baseline | 差距 |
|----------|:------:|:--------:|:----:|
| 前瞻 AUC | **0.739** | 0.681 | +0.058 |
| 前瞻 T3 Recall | **33.0%** | 12.0% | +21pp |
| 前瞻 T2 Recall | **15.6%** | 3.1% | +12.5pp |
| 前瞻 T4+ Recall | 82.7% | **86.4%** | -3.7pp |

**两阶段方案前瞻 AUC (0.739) 接近历史最佳 (0.752)**，但不需要在推理时提供 mask（历史最佳 boundary_boost_frozen 需要 4-channel mask 输入）。

#### 3. T2 挑战的本质

T2 的 GradCAM-border correlation 在 baseline 中已经较高（0.184），attention guidance 反而略降（0.172）。**T2 的核心挑战不在于"模型看不到边界"，而在于 T2 vs T3 的边界特征差异微妙**——需要更精细的层次信息（胃壁哪一层被侵犯），这正是路线 C（方向性标注）的价值所在。

#### 4. Attention Guidance 方案的外部泛化性问题

所有 attention guidance 相关模型的外部测试 AUC (0.62-0.64) 低于历史最佳 (0.659)，说明 GT mask 引导可能让模型过度依赖内部数据的病灶形态分布。**解决方向**：
- 尝试更弱的引导（lambda < 0.05）
- 仅在前 3-5 epoch 使用引导，更早关闭
- 引入外部数据的 mask 预测（用 segmentation model）来扩展引导覆盖

#### 5. 下一步最值得做的事

1. **✅ 确认两阶段方案有效** — 已验证，前瞻 AUC 0.739 > baseline 0.681
2. **尝试更优的两阶段调参** — 先 attention guidance 3 epoch（而非 8），然后 finetune lr=5e-6
3. **路线 B（Video MIL）启动** — 用两阶段方案的 backbone 提取帧特征
4. **路线 C 试点** — 50 张 T2/T3 方向性标注，验证是否能进一步区分 T2/T3
