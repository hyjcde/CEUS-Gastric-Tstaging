\section{Segmentation experiments}
\subsection{Mainline U-Net results}
\begin{itemize}
  \item Comprehensive internal evaluation: mean Dice $\approx$ 0.65
  \item Strict patient-level protocol: prospective Dice 0.713; Putian 2024 Dice 0.433
  \item Predicted mask bank: $\approx$12\,193 images (UNet + ConvNeXt-Tiny, smp)
\end{itemize}

\subsection{SAM2 cascade and SAM3 zero-shot}
SAM2 with ground-truth bounding-box prompts achieved high Dice (oracle upper bound). Cascade mode (UNet coarse mask $\rightarrow$ SAM2 refine) slightly exceeded pure UNet on external data when prompts were stable. SAM3 text zero-shot segmentation was ineffective (Dice $\approx$0), and is not pursued further.

\subsection{MedDINOv3 and nnU-Net explorations}
The MedDINOv3 workspace contains full-image and two-stage segmentation summaries indicating feasibility of full-stomach segmentation, but end-to-end ROI Dice in deployment-like chains remained unstable relative to strict internal protocols.

\section{Morphology-only baseline}
On 9\,959 mask-bearing images, 22/24 engineered features associated with T category (Kruskal--Wallis $p<0.05$). Gradient boosting on morphology achieved AUC 0.706 with T2 recall 7.6\%, supporting use of mask shape as auxiliary signal but not as a standalone clinical model.

\section{AI and diagnostic study reporting checklist (draft)}
Items aligned with CONSORT-AI and STARD principles for prespecified reporting in the final submission:
\begin{enumerate}
  \item Define the intended clinical user (sonographer) and setting (community vs tertiary).
  \item State input data format (static frame vs video) separately for development and deployment claims.
  \item Report patient-level primary metrics with confidence intervals (bootstrap planned).
  \item Disclose train--deploy differences (mask/ROI availability).
  \item Predefine harmful error types (T2$\rightarrow$T1, T3$\rightarrow$T2) for threshold selection.
  \item Provide external validation across $\geq$2 geographically distinct centres.
  \item Release code and model cards; govern data access via multicentre agreements.
\end{enumerate}
